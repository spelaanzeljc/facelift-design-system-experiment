Icons

429 SVG icons in output/icons/. All are 24×24 by default; display at 20px in components. Prefer inline SVG for colour control — set fill: currentColor and apply color on the wrapper.

Usage

Inline SVG (preferred)
<!-- paste SVG inline for CSS colour -->
<svg width="20" height="20" ...>
  <path ... />
</svg>
Image tag (no colour override)
<img
  src="/output/icons/calendar.svg"
  width="20" height="20"
  alt="Calendar">
Tinting with currentColor
/* wrapper */
.icon { color: var(--sys-icon-primary); }

/* on SVG paths */
svg path { fill: currentColor; }

Finding icons
All icons live in output/icons/ as individual SVG files. Names are kebab-case. To find a specific icon, use the filesystem or the CLAUDE.md icon groups table. The page above shows a representative selection — browse the folder directly for the full 429-icon set.
